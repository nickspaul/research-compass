沿用随附记录 A-G1 的既有授权，下面给出两个小型反例设计。参数均为受控构造假设；A-G1 对工程普遍性的“存疑”保持不变。

两个案例共用一个静态两状态模型：目标位于海区 L 或 R，先验概率各为 0.5。每个动作消耗一个时段，成本相同；发现目标即结束，无误报。完整可行动作集及单次发现概率如下。

| 动作 | 目标在 L 时 | 目标在 R 时 |
| --- | ---: | ---: |
| 搜索 L | 1 | 0 |
| 搜索 R | 0 | 1 |
| 广域扫描 B | 0.6 | 0.6 |

模型假定三个动作均可执行，B 在不同次执行中的漏检相互独立。海区大小、覆盖能力和成本关系仅由上述定义给定。

**反例一：候选遗漏。** 只给一个时段，比较候选集 {搜索 L，搜索 R} 与完整集 {搜索 L，搜索 R，B}；两组都在各自集合内精确选优，目标均为最大化截止时的发现概率。

- 缺少 B 时，最优发现概率为 0.5。
- 加入 B 后，最优动作是 B，发现概率为 0.6，增加 0.1。

只有一个时段，不存在牺牲未来收益的选择。这个构造将差距定位到候选集：选择规则即使精确最优，也无法选中未提供的 B。若补齐 B 后仍选搜索 L 或 R，则还存在选择规则或实现方面的问题，不能仅归因于候选遗漏。

**反例二：短视选择。** 给两个时段，始终提供完整的三个动作，并允许根据未发现这一观测更新信念。比较“每步最大化即时发现概率”的贪心策略与精确两步规划；两者拥有相同的动作、信息和两个时段。

- 贪心第一步选 B，因为 0.6 大于搜索单一区域的 0.5。B 漏检对两状态的概率相同，因此漏检后先验仍为各 0.5；贪心第二步继续选 B。累计发现概率为 0.6 + 0.4 × 0.6 = 0.84。
- 两步规划先搜索 L。以 0.5 的概率立即发现；否则确定目标在 R，第二步搜索 R。累计发现概率为 0.5 + 0.5 × 1 = 1。

完整动作集下仍有 0.16 的发现概率差距，因而这个构造不依赖候选遗漏。差距来自即时收益排序忽略了“搜索 L 未发现”对第二步决策的价值。
