## 文件与格式

Skill Creator 自带 `quick_validate.py` 已运行，通过 YAML frontmatter、名称和脚手架检查。本包的 `validate.py` 已通过。检查范围包括目录名称、UTF-8、15项必需资源、维护文档相对链接、Markdown 表格和围栏、18项测试的字段与唯一编号。

另在隔离副本中注入非法名称、缺失引用、本机绝对路径和重复案例编号，4项错误均被校验器检出，见[结构检查负控](runs/structure-controls.json)。这些是校验器测试，不计入Skill行为通过数。

结构检查不会把包含某个词语、标题或模板视为行为通过。运行 Skill 无外部程序依赖；本包校验脚本仅依赖 Python 标准库。Skill Creator 的检查器是开发环境工具，不随包运行。

格式依据为 [Agent Skills 公开规范](https://agentskills.io/specification)，核对日期为2026-10-28。已验证当前开发环境的文件读取与相对路径；没有运行 `skills-ref` 完整规范库，也没有逐个测试所有兼容宿主。

## 行为试验设置

首轮由3个新执行者各处理5项请求。执行者只收到 Skill 位置、案例输入和必要的虚构材料，没有收到预期行为、失败判据或先前答案。同批请求被要求独立处理，但共享同一个执行者会话，因此不是逐题全新上下文。复测T03和T05各使用一个新的执行者。

来源限定为 Skill 与输入，不联网、不读取项目科研文件，不运行科研实验。T16另提供隔离的虚构承诺卡，允许在该隔离位置按请求处理。原始回答按执行时内容保留，未作文字润色；它们是试验观察记录。

执行者与评审者不同。T01至T10及两项复测由独立评分者按原判据逐项评审；T11、T15至T18由root逐项评审。评分依据是实际决定、证据表述和行动范围，各预期项均记录原文或文件比对证据。

宿主为Codex桌面环境，使用协作子代理。精确模型标识未向本次运行暴露，执行者沿用父配置。执行者提供了操作摘要；没有导出完整逐调用系统轨迹，因此“未联网、未运行科研实验”等操作边界没有获得独立系统级审计。T16文件变更另由root直接比较。
