# 科研质量闸门

## 状态、范围与推进

Gate评估的是指定主张和指定范围内的证据准备程度，不是对研究者或整个项目的评分。研究者授权与科学证据状态分别记录。通过不代表获准投入资源、部署系统或发表主张。

| 状态 | 判定依据 | 可继续的行动 |
| --- | --- | --- |
| 通过 | 当前判断所需材料可核查；关键假设已说明；现有检验足以作出范围内判断，未留下足以推翻该判断的未处理问题 | 在既有授权和适用范围内推进；重要研究决定仍由研究者作出 |
| 存疑 | 已有相关证据，但存在会改变判断的冲突、敏感假设或未排除的替代解释 | 优先区分解释的最小验证；经研究者接受风险可继续探索 |
| 阻断 | 已观察到使当前行动或主张失效的问题，如证据泄漏、不公平比较、反例推翻必要前提或要求伪造记录 | 停止依赖该问题的确认性推进，保留原始材料；可修复、缩小主张或另行探索 |
| 证据不足 | 缺少判断所需材料，无法确定支持或反驳；缺材料本身不等于发现缺陷 | 获取关键材料，或开展可明确标为探索的最小验证 |

初次接手时只评估相关Gate，未评估项记“未评估”，不假设通过，也不强制从Gate 1重跑。输出中的当前状态仅使用上表四种；“未评估”只用于总览中尚未启动的Gate。

新证据可使任何状态改变。改变必须列出新增证据、原状态、新状态及原因。关键假设、模型、数据来源、主要终点、预算或主张发生变化时，重新评估受影响Gate及依赖它的后续判断；不自动清空无关的已核验内容。遇到泄漏，先撤回相应独立确认资格，修复后重新评估。

研究者选择“继续探索”只改变行动授权，不改变证据状态。AI不得将自己补出的前提当成事实，也不得因研究者同意或投入已多而宣布通过。若当前结论有错误，应指出具体失效处，避免把局部阻断扩大为整个领域没有价值。

## Gate 1：问题真实性

1. 核心问题：问题是否独立存在；若为受控构造，它回答什么有意义的理论或方法学问题？
2. 已有证据及来源：列出工程记录、领域资料、理论命题、基准定义或原始观察的位置与核验方式；作者模型内观察单独标明。
3. 未证实假设：如缺陷具有领域普遍性、参数代表现实，或构造能揭示可推广机制。
4. 反例或替代解释：缺陷仅由作者动作空间截断、基线实现错误或评估规则造成；修正后是否消失？
5. 当前状态：从通过、存疑、阻断、证据不足中选一项，并说明它针对的具体问题范围。
6. 最小下一步：核查一项独立来源、修正最小基线，或给出一个区分构造缺陷与普遍问题的反例。
7. 研究者决定：是否将该问题作为核心目标；工程、理论或基准研究的定位；是否接受限定范围的探索。

## Gate 2：创新与知识增量

1. 核心问题：在已有研究基础上，最小能成立的新知识是什么？
2. 已有证据及来源：最接近的工作、检索范围与日期、方法差异、推导或初步比较；无法访问全文时注明。
3. 未证实假设：组合产生了新机制、复杂组件必要，或未检索到先例意味着原创。
4. 反例或替代解释：常规组合、简单方法已达到同等效果、只修复自构缺陷，或结论只是已有定理的直接应用。
5. 当前状态：四选一，写明被评估的贡献表述；未做查新时不能宣布全领域首创。
6. 最小下一步：对一篇最接近工作做实质对照，或用简单替代方法检验复杂性是否必要。
7. 研究者决定：选定贡献方向；接受缩小原创性主张、补证据或转向。AI可草拟候选主张，不能自行定稿。

## Gate 3：方法与实验设计

1. 核心问题：设计能否区分核心假设与替代解释，并给出公平、可解释的检验？
2. 已有证据及来源：模型与参数依据、基线实现、预算表、指标定义、分析计划、开发与确认数据划分及版本。
3. 未证实假设：观测独立、生成器代表目标情境、统计方法适用，或预算和信息已公平。
4. 反例或替代解释：保持策略即可达标、额外计算造成收益、同源数据泄漏、理想条件决定方法排序。
5. 当前状态：四选一，区分可执行的探索设计与可冻结的确认设计；执行过探索不构成确认资格。
6. 最小下一步：补一项杀伤性反例、预算匹配比较或独立性检查；冻结前补齐主要终点、失败标准和停止规则。
7. 研究者决定：关键假设和确认方案冻结；主要终点及阈值；重大资源预算。已有明确批准的同版本方案可直接执行。

## Gate 4：结果与证据

1. 核心问题：结果支持多大收益、在哪些条件成立，是否足以排除最重要的替代解释？
2. 已有证据及来源：原始或汇总结果、运行记录、代码版本、失败和排除项、效应与不确定性、开发／确认角色。
3. 未证实假设：零观测事件意味着零真实风险、统计差异具有实用意义、同源仿真支持现实外推，或分解比例具有因果含义。
4. 反例或替代解释：保守不行动造成零负例、简单基线更优、相关观测夸大样本量、选择性报告或测试集反复使用。
5. 当前状态：四选一；对不支持原假设的合格结果可通过此Gate，不能为通过而要求正结果。
6. 最小下一步：复核能改变结论的一项比较，开展独立确认，或缩小结论；不得通过增加有利种子掩盖反例。
7. 研究者决定：保留原假设、修订目标、追加确认或停止路线；新分析是否仅作探索。

## Gate 5：知识贡献与论文主张

1. 核心问题：可靠的新知识是什么，最终主张是否逐条受到证据支持？
2. 已有证据及来源：建立“主张→证据→核验方式→适用范围”对应关系，保留反证与负结果。
3. 未证实假设：机制解释、现实适用性、普遍最优性或因果性超出已有证据的部分。
4. 反例或替代解释：主张依赖未修复的上游问题、代数记账被称为新理论、模型内结论被写成工程保证。
5. 当前状态：四选一；可通过的贡献包括有证据的反例、性能边界和负结果，不要求论文形成正面叙事。
6. 最小下一步：删改一项超出证据的主张、补一项决定性验证，或将推测与已支持发现分开表述。
7. 研究者决定：核心贡献表述定稿、接受的证据边界，以及继续研究或结束当前路线。

## 最小状态记录

记录可放在现有研究日志中，不必建立额外系统。使用 [科研决策记录模板](../assets/research-decision-log.md)，至少保存：

```text
日期与阶段；Gate；评估的主张及范围；证据位置与核验边界；
状态及理由；下一项最小行动；研究者决定及其原始记录位置；
已授权行动范围；待决定事项；受影响的下游Gate；变更原因。
```

例：Gate 4评估“在生成器A下优于保持原方案”。当前只有5,760例零负收益的作者汇总，且保持策略同样零负例，状态为存疑。研究者可批准补做等预算发现率比较；该授权不使“方法优越”通过。若比较显示简单方法更优，阻断原优越性主张，并允许另行审查已获得的适用边界。
