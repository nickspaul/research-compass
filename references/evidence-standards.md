# 证据、有效性与科研诚信

## 证据标签

每项重要判断写出来源位置、实际核验动作和适用范围。以下标签描述证据性质，不是可以机械相加的等级分数；同一项材料可带多个标签。

| 标签 | 使用条件 | 不能据此声称 |
| --- | --- | --- |
| 独立核验 | 已直接检查相关原始材料、完成所述计算或按明确步骤复核；写清核验对象、方法和结果 | 仅凭读过论文就称已复现；把核验代码正确等同于假设或现实代表性正确 |
| 来源支持 | 可定位资料明确支持该陈述；注明是作者报告、用户提供还是其他来源 | 作者声称自动成为已复核事实；多份同源转述成为独立证据 |
| 模型内结果 | 在指定模型、参数、算法、数据生成或数学前提下成立的结果 | 未经检验外推至实际系统、其他分布或工程部署 |
| 合理推断 | 从已知材料作出的解释或推论，列出推理依据和可替代解释 | 将推断写成直接观察、已证因果或唯一机制 |
| 未验证假设 | 为设计或分析暂设的前提，尚无足够验证 | AI补出的设定自动成为事实或Gate通过依据 |

“独立核验”描述本次审查动作；“证据独立性”描述数据、来源和验证过程之间的关系，两者分别判断。例如，AI独立复算同一仿真结果，仍未获得新的外部证据。经严格证明的定理可以是已核验的模型内结果，无须按经验研究的标准降格。

用户提供的假想案例是测试输入。在该场景中可作条件推理，须注明结论以给定条件为前提；不得声称已获得真实原始数据、检索到真实论文或完成真实复现。

## 核验边界

- 有全文而无数据：可检查论证与报告一致性，不能声称原始结果已复算。
- 有代码而未执行：可指出可见的实现问题，不能声称运行通过或数值已复现。
- 有摘要而无全文：区分摘要中的作者声称与未见的方法细节；不补写细节。
- 无法访问文献：说明未核验的具体引用及缺失内容。可提出查证路线，不能编造标题、作者、DOI、引文或“已有研究证明”。
- 有汇总结果而无运行记录：可检查给出的算术与条件关系，不能断言没有失败、排除或选择性报告。

每次只报告影响当前判断的材料缺口，并提出最小获取路径。证据缺失支持“证据不足”，不能单独支持“存在造假”或“研究无价值”。

## 有效性分层

| 层次 | 可回答的问题 | 常用检查 |
| --- | --- | --- |
| 数值重复性 | 同样输入和实现能否得到相同结果 | 固定版本、种子、环境与容差；复算核心结果 |
| 模型内部有效性 | 实现和推导是否符合定义，比较是否公平 | 单位与边界、反例、基线、预算、统计单位 |
| 跨场景稳健性 | 结论是否在声明的扰动与场景范围成立 | 参数敏感性、失效区间、生成机制变化、排序变化 |
| 外部有效性 | 模型结论能否迁移到目标对象或环境 | 独立来源数据、校准、外部模型、适用人群与分布差异 |
| 工程可用性 | 在真实约束下是否改善实际决策 | 成本、时延、可行性、失败后果、执行约束与实际验证 |

同一生成器产生的更多场景可支持所覆盖条件下的稳健性，不能自动支持外部有效性。更换生成器也需检查是否共享同一不现实前提。理论研究按命题前提评价，无须承诺工程落地；声称工程收益时则需要对应证据。

## 统计与评价检查

1. 明确估计对象与观察单位：平均什么、相对于谁、按任务／对象／批次还是随机种子计样本？成对比较保留配对；重复测量、同一场景衍生样本和相关运行不得直接当作独立观测。
2. 同时评估效应大小、不确定性和实际阈值。p值不说明效应重要程度；不显著不证明等效。等效或非劣性结论需要相应界值、设计和分析依据。
3. 对零事件说明观察数量、事件定义和采样过程。5,760例零负收益不能保证真实风险为零；概率界限依赖独立性、分布与抽样假设。没有验证这些前提时，不把名义样本数直接代入风险保证。
4. Bootstrap与其他重采样须匹配真实采样单位和依赖结构，记录重采样对象、区间方法及适用条件。它们估计给定数据和假设下的不确定性，不产生新的外部样本，也不修复错误模型。
5. 检查主要指标、实用阈值、多重比较、调参选择及停止规则的时间顺序。确认分析按事先确定的方案解释；看过结果后增加的分析保留为探索。
6. 报告拒绝／保持比例、计算成本、不可行结果及完整分母；核对是否通过少行动或改变可行域改善风险指标。安全性与收益应共同评估，必要时比较风险与收益的权衡。
7. 缺少足够信息时给出条件结论及补证方案，不编造功效、置信区间、显著性或未运行的统计检验。

## 描述、代数与因果

先核对分解的定义、分母、参考基线、残差和加总是否成立，再判断它回答了什么问题。将损失分成候选阶段80.51%和认证阶段19.49%的恒等式，可作为该口径下的描述性记账；它本身不证明新理论、机制归因或“改善候选阶段即可因果地挽回80.51%”。

改变候选阶段可能同时改变后续认证、候选难度和交互项。因果归因需要明确干预、对照、识别假设及可能的混杂；可用冻结其他条件的消融或交叉实验检验，但仍须说明这种干预所支持的范围。代数恒等式若形成有用诊断工具，需另证诊断效用和可推广性，不能只凭表达复杂度评价创新。

## 诚信与数据处置

保留原始材料、失败运行、排除理由和版本。清洗、更正、排除、重标注和删除须区分；在重要数据修改前说明范围、理由及对分析的影响，并确认已有授权。可在授权内创建可回溯的派生数据，不覆盖原始证据。

发现泄漏或不公平比较时，先定位受影响结论，保留记录并暂停依赖它的确认性主张。补做探索可帮助修复方案；被污染的测试集不能通过更名恢复独立性。修复后的确认须有合适的新证据或重新隔离方案。

不得伪造实验、引用、证明、复现、失败日志、授权或事前承诺。研究者可以授权探索和资源使用，不能通过授权把不真实的记录变成事实。对疑似问题使用“已核验事实／作者声称／审查推断／尚未证实的怀疑”分别表述，避免把质疑写成定罪。
